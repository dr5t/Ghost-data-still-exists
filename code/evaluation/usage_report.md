## 1. Execution Overview

The final submission output `output.csv` was generated by executing `code/main.py` against all 518 evaluation requests in `dataset/deletion_requests.csv`.

The audit pipeline is architected as an in-memory, deterministic Python deletion-audit engine. It leverages:
- High-performance exact indexing of user identity tokens (current and historical emails, names, phone numbers, and SHA-256 hashes);
- SQLite-driven snapshot analysis of primary and failover replica tables;
- Direct JSON and log document token extractors;
- PDF document parsing via `pypdf`;
- Pure deterministic policy logic applying the 15 statutory deletion rules.
